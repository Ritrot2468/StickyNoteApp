
StickyNoteApp is a Java-based application designed to provide users with virtual sticky notes for quick and easy note-taking.

## Features

- **Create Notes**: Quickly add new sticky notes to your workspace.
- **Edit Notes**: Modify the content of existing notes effortlessly.
- **Delete Notes**: Remove notes that are no longer needed.
- **Persistence**: Notes are saved and remain available even after restarting the application.

## Technologies Used

- **Java**: The core programming language used for development.
- **Gradle**: Employed as the build automation tool.
